# User Management CRUD App

## A React-based CRUD application for managing users with form validation and API integration.

## About the Project

This project is a User Management System that allows you to:

- Create new users
- View user list
- Edit existing users
- Delete users

The app uses a fake API and demonstrates real-world frontend patterns.
